# Threads 防詐屏蔽擴充功能 — 安裝說明

## Chrome / Edge 安裝方式

1. 開啟瀏覽器，前往 `chrome://extensions/`
2. 右上角開啟 **開發人員模式**（Developer mode）
3. 點擊 **載入未封裝項目**（Load unpacked）
4. 選擇本資料夾（`browser-extension/`）
5. 擴充功能安裝完成，前往 [threads.net](https://www.threads.net) 即可自動生效

## Firefox 安裝方式（暫時）

1. 前往 `about:debugging#/runtime/this-firefox`
2. 點擊 **載入暫時性附加元件**
3. 選擇本資料夾內的 `manifest.json`

---

## 使用說明

點擊瀏覽器工具列的 🛡️ 圖示開啟控制面板：

- **直接隱藏**：詐騙貼文從頁面移除（預設）
- **顯示警告**：詐騙貼文顯示橘色警告條，標示命中的詐騙類型，點 ✕ 可手動忽略

Popup 大數字顯示本頁已屏蔽的貼文數，重整頁面後歸零。

---

## 後端設定（選填）

未設定後端時，擴充功能僅使用本機偵測規則（L2.5 + L4 正則）。  
若要連接詐騙資料庫後端以獲得更高精準度：

1. 開啟控制面板，在「後端設定」填入 **Gateway URL**（例如 `https://gateway.sggcthreadsscamrev.dev`）
2. 若後端設定了 EXT_TOKEN，也填入 **EXT Token**
3. 狀態燈轉綠即代表已設定，之後貼文會優先查詢後端資料庫

## 偵測的詐騙類型

### 本機規則（離線可用）

| 層級 | 類型 | 說明 |
|------|------|------|
| L2.5 | 引導離站（LINE 外導） | `lin.ee`/`line.me` 直連、動詞＋LINE/賴、`@帳號` 格式等，排除 LINE Pay 與反詐語境 |
| L4 | 假出售 | 出售／轉讓／訂購 + 私訊或 LINE 聯繫 |
| L4 | 投資詐騙 | 投資獲利話術，含「飆股引流」與「N 年經驗宣稱」變體 |
| L4 | 假徵才 / 假代工 | 徵人／居家代工 + 引導應徵 |
| L4 | 假贈品 / 假抽獎 / 假虛寶 | 免費送出 + 私訊領取 |
| L4 | 交友詐騙 | 援交／固友／包養，及「搬來某地找朋友」「哭不代表悲傷」等固定台詞 |
| 補充 | 投資話術 / 假兼職 / 緊迫感 / 假見證 | 穩賺不賠、在家賺錢、名額有限、成功出金截圖 |

### 後端額外覆蓋

| 類型 | 說明 |
|------|------|
| 已確認詐騙 URL | 人工審核標記的詐騙貼文直接命中 |
| 詐騙 LINE 帳號 | 從確認案例萃取的 LINE ID 資料庫比對 |
| BERT 語意判斷 | 中文模型對灰色地帶文字做語意分類（F1=0.9643） |
| LLM Judge | Groq 對邊緣案例再判斷 |

## 隱私說明

- **未設定後端時**：所有偵測均在本機執行，**不上傳任何資料**
- **設定後端（Gateway URL）後**：會將公開貼文的文字（最多 500 字）與貼文網址上傳至你所設定的後端進行比對
- 僅讀取頁面上已公開顯示的貼文文字
- 不蒐集使用者個人資訊
