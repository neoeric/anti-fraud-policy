# Threads 防詐屏蔽插件 — 安裝說明

## Chrome / Edge 安裝方式

1. 開啟瀏覽器，前往 `chrome://extensions/`
2. 右上角開啟 **開發人員模式**（Developer mode）
3. 點擊 **載入未封裝項目**（Load unpacked）
4. 選擇本資料夾（`browser-extension/`）
5. 插件安裝完成，前往 [threads.net](https://www.threads.net) 即可自動生效

## Firefox 安裝方式（暫時）

1. 前往 `about:debugging#/runtime/this-firefox`
2. 點擊 **載入暫時性附加元件**
3. 選擇本資料夾內的 `manifest.json`

## 使用說明

- 點擊瀏覽器工具列的 🛡️ 圖示開啟控制面板
- **直接隱藏**：詐騙貼文從頁面移除
- **顯示警告**：詐騙貼文顯示橘色警告標籤，點 ✕ 可手動忽略

## 後端設定（選填）

未設定後端時，插件僅使用本機關鍵字規則。若要連接詐騙資料庫後端：

1. 開啟控制面板，在「後端設定」填入 **Gateway URL**（與選填的 **EXT Token**）
2. 按 **授權並測試連線** — 自訂網域需要授權一次（瀏覽器會跳出權限確認）
3. 狀態燈轉綠即代表連線成功，之後貼文會優先查詢後端資料庫

## 偵測的詐騙類型

| 類型 | 說明 |
|------|------|
| 引導離站 | 要求加 LINE、私訊、Telegram 等 |
| 投資詐騙 | 帶單、穩定獲利、出金截圖等 |
| 假兼職 | 在家賺錢、接單做任務、日薪保證 |
| 製造緊迫感 | 名額有限、限時優惠 |
| 假見證 | 成功出金截圖、感謝老師 |
| 交友詐騙 | 結合交友與投資的話術 |

## 隱私說明

- **未設定後端時**：所有偵測均在本機執行，**不上傳任何資料**
- **設定後端（Gateway URL）後**：會將公開貼文的文字（最多 500 字）與貼文網址上傳至你所設定的後端進行比對
- 僅讀取頁面上已公開顯示的貼文文字
- 不蒐集使用者個人資訊
